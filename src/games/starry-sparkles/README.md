# Starry Sparkles

Paint the sky with colorful fireworks, or light the large outlined stars to draw a picture. Each star can be tapped in any order; neighboring lit stars connect. Finishing a kite, house, or crown brings a three-firework finale, then another picture appears. Ordinary fireworks remain available anywhere in the sky, and color choices never advance the picture by themselves. There is no deadline or wrong tap.

Six large paint buttons select a color and demonstrate it. Space and play keys launch fireworks around the sky; held input counts once. The upper-right sound button mutes immediately. Gentle original audio, six reusable firework slots, and fixed star/line pools keep long sessions bounded.

This is a self-contained Squish 1.5.0 game with original vector art and locally generated PCM WAVs. No downloads or services are required. Run `node testRunner.js ./test/games/StarrySparkles.test.js` from homegames-core for input, sky-picture, audio, and native-frame checks.
