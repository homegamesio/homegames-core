# Image Gallery

A simple gallery to display images. Fill in asset IDs in metadata.assets.

Consolidated from `butt2-main.zip`. Game code and authored media live in this folder. Original `LICENSE` is preserved.

Catalog: Hidden for review (`isTest: true`). Image display demo; retain for asset testing.

Enable `TESTS_ENABLED` to try hidden games. Remove `isTest: true` from metadata to restore a game to the default catalog.

See [the consolidation review](../../../docs/game-consolidation.md) for archive decisions, screenshots and verification limits.
