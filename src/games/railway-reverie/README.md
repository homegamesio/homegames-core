# Railway Reverie

Explore a shared living model railway through independent cameras. Watch trains, towns, wildlife, traffic, weather, and tiny contextual events unfold across a huge polygon world.

Consolidated from `idk-main.zip`. Game code and authored media live in this folder. Original `LICENSE` is preserved.
