# Heart Catcher — archived canvas experiment

Imported from `djdjdjd-main.zip`. The original source is preserved as
`legacy-canvas.js`. It uses a canvas/context API and has no Homegames metadata,
scene layers or standard input contract. There is deliberately no `index.js`,
so local discovery does not offer a broken game. Port it to Game/GameNode before
promoting it. Homegames-authored code is MIT licensed; separate media notices remain applicable.
