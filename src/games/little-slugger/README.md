# Little Slugger

A gentle, colorful baseball toy for little hands. Teddy waits with a ball on a tee: tap anywhere or press Space to make a guaranteed hit. Watch the ball fly to a smiling star while the animal crowd cheers. A fresh ball appears automatically, ready whenever the child is.

There are no misses, scores, countdowns, or losing. Each hit changes the ball's stitch color and cycles among three star targets. Repeated taps during a hit make extra sparkles. Quiet original musical sounds can be turned off with the upper-right sound button.

Native Homegames game using Squish 142; one player; all art and audio generated in this game folder. Touch, mouse, keyboard and gamepad supported. No network requests or external assets are required.

Run the focused checks from homegames-core with `node testRunner.js ./test/games/LittleSlugger.test.js`.
