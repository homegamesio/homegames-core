# Common Ground

A calm shared city builder where players independently explore one living city, place roads and zones, and watch buildings, traffic, population, and revenue grow over time.

Consolidated from `common-ground-main.zip`. Game code and authored media live in this folder. Original `LICENSE` is preserved.

Catalog: Internal test / review. Excluded from the launch collection; source and assets are preserved. See [the launch catalog review](../../../docs/launch-catalog-review-2026-10-17.md).

Enable `TESTS_ENABLED` to try hidden games. Remove `isTest: true` from metadata to restore a game to the default catalog.
