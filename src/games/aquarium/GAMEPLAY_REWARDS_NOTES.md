# WORLD upgrades: visuals now change gameplay

Every permanent WORLD spectacle now has a numeric mechanic attached to the visible object. The visual is the physical proof that the shared aquarium became stronger.

- **Sun Shafts** — +15% water food value per level (max +60%).
- **Giant Kelp** — +12 fish capacity per level (max +60 fish).
- **Crown Reef** — +20% water bite rewards per level (max +80%).
- **Nebula Clouds** — +20% cosmic food value per level (max +80%).
- **Orbital Sanctuary** — +40 alien capacity per level (max +160 aliens).
- **Horizon Lights** — -8% current/future Era goal requirement per level (max -40%). Buying a level can immediately raise a monument if the reduced threshold has already been earned.
- **Aurora Whales** — golden visitor jackpot increases by +25x per level (50x base -> 75x -> 100x -> 125x) and the next visitor interval is 10% shorter per level (up to 30% sooner).
- **World Crown** — +25% all bite rewards per level (max +75%).

All effects survive New Era resets along with their visuals. The WORLD shop now displays the current numeric effect and the next level's effect directly in the row.

The existing 60 Hz behavior, feeding fix, Horizon progression, visual render caps, and golden-visitor mechanics remain intact.
