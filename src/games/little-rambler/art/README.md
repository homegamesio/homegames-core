# Little Rambler scenery

Created for this game with the built-in image generation tool (not the fallback CLI). These are original generated backgrounds; no Crunchling Adventure imagery was used as input. Pip, furniture, gameplay objects, and interface are drawn separately with Squish geometry.

Each `.png` is the original output, each `.jpg` is its quality-85 runtime encoding, and each `-data.js` embeds that JPEG for native Homegames local play. All three source images are 1672 × 940. Compression changes encoding only.
