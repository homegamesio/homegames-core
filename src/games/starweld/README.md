# STARWELD

Build a battleship from the wreckage. Steer a salvage ship through four sectors, weld eight kinds of weapons and systems onto your hull, and dismantle four enormous bosses. Automatic weapons, mouse/touch or keyboard steering, and a lifesaving shockwave. A complete solo campaign with checkpoint saves.

Consolidated from `astra-testing-main.zip`. Game code and authored media live in this folder. Original `LICENSE` is preserved.

Catalog: Internal test / review. Excluded from the launch collection; source and assets are preserved. See [the launch catalog review](../../../docs/launch-catalog-review-2026-10-17.md).

Enable `TESTS_ENABLED` to try hidden games. Remove `isTest: true` from metadata to restore a game to the default catalog.
